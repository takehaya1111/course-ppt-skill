# v0.5.2：把原版规则落实到实际审阅

此前的适配已把原版视觉规则交给独立审阅者，但程序可以接受“逐页明列两处未处理软问题、整体仍通过”的矛盾报告。这个缺口会让已写入技能的规则停留在提示层。

本版继续使用原版设计纲、执行锁、逐页作者与导出器。主要变化：

1. 派发包明确保存原版规则及阶段入口、完整§I阅读方式、§V间距原文、§IX页角色、作者画布和实际渲染像素。缺失或冲突的阅读方式不能默默通过。
2. 独立报告需记录原版规则的实际覆盖、观察和不适用理由，末态补阅读目的、间距与页面角色的检查；其他显隐状态仍实际看图，可以说明变化并继承共同判断。
3. 未处置硬问题、多个剩余软问题、缺覆盖、问题与通过结论矛盾时拒绝交付；保留原版允许合理非对称、不确定时不乱改以及最多一处有理由剩余软问题的边界。整套重复问题须有整套决定。
4. 按高频教学任务选用五张固定来源内容页，明确原作者怎样改变了规划构图、哪些表达义务保留、哪些形式不能照搬。图文参照随完整技能包分发，不增加封闭页型库。

不合入按文字左缘猜卡片间距、忽略段落/变换、或一律要求条款标签大于正文的试验检查。间距继续从原版§V读取，没有另造`spacing`锁段，也没有修改上游文件。

升级后旧审阅须重新实际检查，不补填默认通过。宿主若绕过技能入口、未加载原版分支或缺看图能力，技能文本无法强制其执行；应保留真实失败和能力边界。程序验证覆盖和证据关联，不能自动认证观察是否认真、审美是否相同。独立生成试样与软件测试分别记录，不将软件测试通过当成整套课程或跨模型质量证明。

其他宿主本地修改先比较并备份；不要覆盖仍在工作的安装目录。公开包只含技能、上游和公开参照，不含私人课程资料。
