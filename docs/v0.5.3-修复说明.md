# v0.5.3：选择性吸收本地补丁

本地交接提出了渲染可复现、失败留证、警告可见和整套复查等真实需要。本版按原版机制和正负反例筛选，合入有效部分并修正实现缺口。

## 渲染

- LibreOffice仍是用户明确选择的替代软件分支，不以它冒充WPS/PowerPoint。优先用Poppler；自动发现不到时可以使用技能内的PDFium光栅化脚本，记录工具身份、版本、脚本摘要和采用原因。
- 明确指定的工具路径有误时直接报错，不悄悄更换。备用脚本的可用性探测真实导入依赖，不用固定版本字符串冒充配置成功。
- 转换进程成功退出但未生成PDF时，只重试一次；保留每次输出、错误和目录状态，最终失败不丢掉前次线索。
- PDFium依赖按可选安装组固定版本，默认核心环境不强制安装；具体命令见技能INSTALL.md。
- 显式`--output-dir`可将本次副本与渲染证据放到全新目录，保持原工程与源文件绑定、不覆盖旧记录；用于路径等环境因素的排障，不自动更换软件或迁移项目。

## 原版提示与审阅

- 构建结果显示原版作者稿写法提示、真实条数/文件数和原始证据。只针对原报告实际提到的样式或坐标工具给建议，使用当前Python，保留原版“可保持显式写法”的选择；不会自动改源。
- 修复逐页审阅依据可截成任意子串的漏洞，要求完整保留包内本页任务；换行和首尾空白可规范，关系、条件和点击要求不能被删。
- 发现缺陷后复核本次整套同类适用页及状态，在已有审阅记录写实际覆盖和合理例外。不因局部修复通过就宣告同类问题已解决。

## 保留的设计边界

不采用每页必填`Structure: cols/bands/index`的门禁，也不要求所有条款索引大于正文。原版`Composition`是可调整的建议构图；教学含义、关系和用户固定约束应保留。单列缩进、变换、透明元素等能让该补丁的几何统计误报或漏报，不能用这些数量证明页面表达正确。

检查器应同时验证已知缺陷与合法设计；“某页出现任意提醒”不能算作目标缺陷检出。程序测试与真实渲染分开记录，均不自动证明审美、课堂效果或跨模型一致。
