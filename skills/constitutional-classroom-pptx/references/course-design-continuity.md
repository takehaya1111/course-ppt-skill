# 独立讲次怎样形成整套感

本文件用于同一课程分次制作。继承的是有来源的设计依据与可辨认的共同语言，各讲仍按自己的内容设计。复用上游 [plan-core.md](../vendor/ppt-master/skills/ppt-master/references/plan-core.md) §4 的节奏和持续对象、[原版设计纲](../vendor/ppt-master/skills/ppt-master/templates/design_spec_reference.md) §III—V，以及 [设计锁](../vendor/ppt-master/skills/ppt-master/templates/spec_lock_reference.md) 的稳定色彩和字体角色；不新建页面生成器或每讲一样的版式表。

## 1. 每次开工实际读取同一依据

先定位课程已有的共享设计说明、指定代表工程的 `design_spec.md` / `spec_lock.md`、已认可的实际内容页及其适用范围。它们是**本门课程的运行输入**，不写成全局技能默认样式。只读文件名或记得“暖色”不足以继承，必须读取具体说明并实际看代表页。

在本次 `design_spec.md` §I/§III 的简短来源说明中记录：来自哪个课程依据、版本/哈希、哪些代表文件与页码、教师认可了什么、本次继承什么及有何必要变化。冻结实际采用的文件到本次 `sources/`，沿用 `course-project.json.sources` 登记；代表图及原件身份可用现有来源记录保存。来源说明不增加新的锁字段、并行设计纲或每讲审批环节。

- 有课程明确指定版本时沿用该版本，不被另一个目录中的“最新版”悄悄替换。
- 只有已认可小样时，写明“小样已认可；作为本次延续起点”，不能冒充整门课程规范已获认可。
- 还没有共同依据时，从本次任务和参照形成原版设计纲；标为当前候选设计依据，后续制作可按用户认可或委托范围继承。不得假装已做跨讲比较，也不为填表要求教师先建文件。
- 发生本讲任务与共享样式冲突时，保全内容和投影可读性，说明具体调整。字体缺失、材料比例或特殊引文可作局部适配；反复出现的新角色回到原版策划更新依据，不能用每页临时例外逐渐换掉整套身份。

## 2. 继承哪些，开放哪些

| 必要的共同特征 | 由内容决定的变化 |
| --- | --- |
| 标题、正文、原文、注解的字体角色和层级 | 页面数量、拆合、信息密度与文字组织 |
| 背景、正文、强调、材料注释的稳定色彩角色 | 当前页面的主体位置、留白、图文比例与局部配色 |
| 线条、标注、图片与原文材料的处理方式 | 采用原文对读、照片观察、图解、数据图或纯文字 |
| 已出现对象的名称、身份与有教学含义的视觉标识 | 构图、形状、图标、图片裁切和关系的具体表现 |
| 适用的导航、出处及简单点击习惯 | 是否需要导航、哪些对象本页应常驻、点击次数和揭示对象 |

共同特征只纳入本课程实际采用并具有身份或教学作用的项目；不强迫每页出现全部元素。共同对象只在含义相同时继承，颜色含义不能悄悄互换，也不能把“所有机关永远矩形”“所有人永远圆点”升级成通用禁令。

将本次实际继承结果写入原版 §III—V 和相应 `spec_lock.md`。锁只投影原版允许的角色与字段；当前课程说明中的自由度不塞入 `forbidden`。旧工程的内容、页序、素材清单和点击不随风格一起复制。

已有**有效模板工作区**且只需继承风格时，按 [strategist-template.md](../vendor/ppt-master/skills/ppt-master/references/strategist-template.md) 使用 `template_reuse_scope: style`、`pptx_structure.mode: flat`，不复制固定页面或母版映射。只有参考课件而没有模板工作区时，读取其风格依据并进行自由设计即可；不要假造模板安装记录，也不要为整套感把普通课件强行升级为母版模板。

## 3. 实际比对，而不是靠同色推定

制作沿用原版逐页九步和每五页重读锁。早期回看及最终审阅时，将本次代表内容页与已采用的跨讲代表页放在一起看；小样查看全部页，整讲选择覆盖不同教学任务的代表页做跨讲比较，同时保留原有逐页终态及显隐检查。

审阅者应同时拿到原材料、当前页面、课程设计依据和旧代表页。早期回看使用本次已绑定的 SVG 快照预览，最终审阅使用实际 PPTX 渲染；按[设计审阅](design-review.md)分别记录，不为早期回看强制提前导出。两种比较各回答自己的问题：

- **对原材料**：主张、主体、条件、证据、先后与揭示时机是否保全；画面是否暗示了原稿没有的关系。
- **对课程代表页**：标题与正文角色、强调与注解、材料处理、线条和共同对象是否相认；不同构图是否仍表现相同的设计语言。指出实际继承的特征；有变化时说明理由，无必要变化时如实记录，不为展示变化而改动。若现有参照不足以判断某项，如实限定结论。

在现有 `deckReview.continuity` 写课程来源/版本、实际比较的页和具体观察；`referenceComparison` 与 `designTarget` 继续判断优秀内容页的完成度。外部标杆回答“做得够不够好”，课程代表页回答“是否属于同一套”，不能互相替代。没有旧讲次代表页时只报告本次内部一致性，不宣称已验证跨讲整体感。

以下均不足以证明设计通过：字段齐全；同一背景色或页脚；每页都换一种构图；原稿条件只在备注里。最终交付不能仅比较源 SVG 而未查看实际 PPTX；早期 SVG 快照预览仍是有效的阶段证据。发现不一致时调整本次角色或具体表达，保留适合内容的差异；不得通过统一成一种版式消除差异。

跨讲比较是原版早期/最终设计审阅中的一个观察角度，不新增教师审批，不要求返工未在本次范围内的旧课程。
