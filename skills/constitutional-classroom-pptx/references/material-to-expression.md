# 从课程材料提炼到画面表达

在原版策划时读本文件；制作时沿用已经形成的页卡，不再另跑一套分析流程。它补充材料读取和教学验收，主干仍是上游 [plan-core.md](../vendor/ppt-master/skills/ppt-master/references/plan-core.md) §1—4 的目的、阅读方式、完整内容与页序节奏，以及 [executor-base.md](../vendor/ppt-master/skills/ppt-master/references/executor-base.md) §2.2 的逐页九步。制作关系图时复用 [executor-structure.md](../vendor/ppt-master/skills/ppt-master/references/executor-structure.md)，先确认关系，再决定是否及如何画出它。

## 1. 分层读取，不以层级代替判断

| 材料 | 实际读取与提取 | 写入现有设计纲 |
| --- | --- | --- |
| 总纲 | 通读课程目标与知识分工；查本讲所在位置、已学前提及后续讲次承担的任务 | §I 的受众起点、目的与内容边界；不把整门课目标全部塞进本讲 |
| 分纲 | 完整读取本讲目标、重点、深度、顺序和与前后讲的联系 | §I 的本讲任务；§IX 的理解推进与必要回扣 |
| 完整口播成稿 | 通读本次制作范围全文及必要前后文，辨认主张、主体、动作、关系、证据、条件，以及提问与揭示顺序 | §IX 的 Audience move、Core message、Content、Relationships、Notes、Motion；原文定位留在相应页卡 |
| 原始材料、图片、引文 | 核身份、原文、适用范围、出处和可观察细节；材料图片中的文字也可能是证据 | §VIII 的素材身份及用途，§IX 的观察任务和字面保留要求 |

小样读取所在教学段的完整内容，并查总纲/分纲和相邻段落所需上下文；这不授权制作整讲。未提供总纲或分纲时利用现有材料继续，不要求教师补制一张表，但如实写明无法确认的课程分工，不能声称完成跨讲内容核对。

三层材料不是“总纲总能覆盖口播”的机械优先级。先以用户当前明确指定的文件与认可范围识别版本，再按问题处理：

- **只是粒度不同**：总纲的一项在分纲或口播中展开，保留展开，不当成冲突。
- **旧稿已被明确替换**：记录替换关系，使用认可现稿；旧文件保留为历史来源。
- **设计建议不同**：未被教师固定的页数、卡片、配色可以按本讲任务调整，并在原页卡记录决定。
- **事实、条件、主张、范围或已认可讲述顺序冲突**：定位双方原文，写清画面会造成什么差别；不要暗选一个、拼成新结论或以图形掩盖。证据足以确认的版本问题自行处理；仍影响教学内容且无依据裁决时只就该处请求澄清，其他部分继续。核实事实不自动授权改写教师定稿。

## 2. 提炼的是表达义务，不是页面套式

在已有 §IX 页卡中，用足够短的中文保留下列决定；沿用 [教学定制需求模板](teaching-customization-template.md) 的条目，不增加另一份逐页纲或固定机器字段。

1. **材料说了什么**：保全主体、动作、对象、关系、条件及证据位置，区分明确陈述和作者整理。不能用关键词摘录代替完整意思。
2. **学生需要理解什么变化**：例如从“两个名称等同”到“它们指向不同权利”，而非只写“了解某概念”。由原稿及大纲支持，不能在画页时临时发明教学目的。
3. **屏幕必须承担什么**：学生需要同场辨认的对象、相同项与变化项、必要条件、原文证据及观察顺序。其余解释进入完整备注，但限定当前可见结论的条件不能只藏在备注中。
4. **怎样才算表达正确**：写出可在页面或某次点击中看见的现象，并指出最可能的误读。把“主张准确”和“视觉表达准确”一起检查。

随后执行原版九步：目的与理解变化 → 阅读方式 → 是否需要几何表达关系 → 页面节奏 → 图文及资源组合 → 实际调用模块 → 构图 → 形状 → 坐标。上游 §IX `Relationships` 保存内容中的对象与关系，`Composition` 只是宏观参考；不在策划时给每个概念绑定矩形、颜色或坐标。文字对读、真实图片或对象位置更准确时可采用，图形数量不代表理解深度。

## 3. 三个正反例

以下为**公开分发用的合成教学片段**，不对应真实法规、史实或私人课程。展示的是判断方法，不是可换词批量出图的页面模板。

### 例一：同一对象中，什么变、什么不变

**合成原稿**：“馆藏器物借到另一家展馆。在约定展期内，保管地点和展出方发生变化。先指出变化的部分，再判断是否发生所有权转移。器物还是同一件；改变的是展出安排，所有权没有变化。”

- **语义与任务**：区分所有权与限时展出安排；同一器物、原权属保持，展出方和地点变化，展期是限制。
- **屏幕需要**：让器物及不变关系持续可辨；明确变动的是展出安排，限定语贴近该变化；结论按原稿时机揭示。可用实物图、前后对读或关系图，具体构图留给作者。
- **正确观察**：初态能辨认同一器物；学生判断后，揭示状态清楚标示“所有权未变”；任何移动线均有真实动作的标注，期限没有脱离动作。
- **错误反例**：整件器物连同所有权标识一起移交给新馆；无说明的双向箭头暗示双方都有所有权；先把答案放大常驻而破坏原稿判断题。颜色好看和备注里有完整条件都不能挽救这些误读。

### 例二：条件、可选行为和结果不同

**合成原稿**：“已预约且携带有效证件的读者，可以申请进入特藏阅览室；申请以后仍需核验。申请资格不等于已经获准进入。”

- **语义与任务**：两个条件同时满足才具备申请资格；申请、核验、获准进入是不同状态；“可以申请”不是“必须申请”。
- **屏幕需要**：两项条件共同限定申请；把核验与进入结果区分，避免暗示申请必然成功。核验结论若不在材料中，不补造具体通过率或拒绝理由。
- **正确观察**：当前屏幕上的“可申请”旁能找到两项条件；学生能区分申请者与获准者；点击显示核验时，仍可认出同一申请对象。
- **错误反例**：预约→证件→申请→进入的一条无条件成功流水线；把“且”画成二选一；为了版面干净删掉证件条件；让每个步骤面积表达材料没有提供的难度或耗时。

### 例三：先观察证据，再形成解释

**合成原稿**：“旧版活动通知写‘现场报名’，新版增加‘网上报名’。请先圈出新增文字，再说明两种报名方式现在是什么关系。”

- **语义与任务**：比较同一字段的版本变化；现场方式未消失，新增线上选择。学生先观察原文，再解释并存。
- **屏幕需要**：版本身份与原文可读、对应基准一致；新增文字容易定位，初始状态不提前显示解释性结论。可以原文对读或局部放大，不必把文字材料转换成流程图。
- **正确观察**：原文同场比较且文字完整；第一次观察只要求找差异，后续状态才说明两种方式并存；来源与教学注解的字体角色可区分。
- **错误反例**：只剩作者概括，无法回看证据；新版不显示保留的现场方式，造成替代误读；初态直接标“并存”，失去原稿安排的观察活动。

以上正确观察仍需真实页面验证。专业完成度由主图、层级、文图配合和细节执行体现；满足语义最低要求不能自动宣布达到参照水平。
